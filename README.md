# Restaurant Page 🍽️

Una página web de restaurante construida con Webpack y JavaScript vanilla.

## 🚀 Inicio Rápido

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Build para producción
npm run build
```

## 🛠️ Tecnologías

- JavaScript (67.5%)
- CSS (28.3%)
- HTML (4.2%)
- Webpack

## 📋 Características

- Navegación dinámica
- Diseño responsivo
- Hot reload en desarrollo
